# План первой версии

Решение 17 октября 2026: первая версия — бот «Сигнал лаборатории» на реальном счёте около 10 USDT. Это проверка механики исполнения, а не доходности.

## Готово

- Интерфейс (Обзор, Боты, Лаборатория), локальный API, SQLite, импорт и экспорт настроек, сервер 24/7 (`SERVER.md`).
- Запись данных многих монет Binance (`LEVEL_BREAKOUT.md`) и лаборатория сигналов: 10 событий, сессии, спред для пипсовки, проверка зафиксированной гипотезы (`SIGNAL_LAB.md`).
- Бот «Сигнал лаборатории» по обработанным записям: размер от риска с комиссиями, стопы по ходу цены, лимиты (`SIGNAL_BOT.md`).
- Старые стратегии («Поводырь», «Импульс», пробой уровня как бот) и страница «Журнал» удалены.

## Дальше по порядку

1. **Подтверждение сигнала.** Гипотеза проверяется на событиях с 16.10.2026, нужно 50 эпизодов на сигнал. Без подтверждения реальный счёт проверяет только механику.
2. **Живой режим.** Бот торгует виртуально прямо на потоке записи данных, сделки появляются сразу. Решения те же, что по записи: живой результат обязан совпадать с повторным прогоном этой же записи.
3. **Торговый адаптер.** Binance USDT-M через TigerX. Сначала проверить совместимость API TigerX и фактические комиссии, работать в тестовой сети Binance.
   - Заявки: рыночный вход, стоп на бирже, выход по времени, `reduceOnly`.
   - Изолированная маржа и плечо, шаг цены и количества, минимальный номинал.
   - Сверка позиций и заявок с биржей после перезапуска и разрыва, защита от двойных заявок при потерянном ответе.
4. **Контроль риска.** Предел убытка за день и на весь счёт, предел номинала и плеча. Кнопка «остановить и закрыть всё». Бот не торгует при устаревших данных.
5. **Ключи и реальный счёт.** Ключи вводит пользователь, они хранятся только на его компьютере и не попадают в Git и базу. Первые реальные заявки — только после явного решения пользователя, на минимальном размере.
