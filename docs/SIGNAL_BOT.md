# Бот «Сигнал лаборатории»

Бот торгует один сигнал лаборатории (`docs/SIGNAL_LAB.md`) на всех монетах записи данных Binance. Это симуляция: ключей нет, реальные заявки не отправляются. Код: `server/TradeBot.Api/SignalBot.cs` (`SignalParameters`, `SignalEngine`, `SignalBots`), интерфейс — `src/SignalBot.tsx`.

## Как он работает

Бот читает **обработанные записи** — те же, что лаборатория. Запуск — это момент, с которого бот торгует: «с этого момента» или «с даты» в прошлом (тогда он сначала проходит записи с этой даты). Новые сделки появляются после обработки каждой новой записи. При непрерывной записи это примерно раз в час. Результат зависит только от записей и настроек, которые были при запуске, поэтому повторное чтение даёт те же сделки. Остановка фиксирует конец запуска.

Решения принимаются только по данным до момента события:

- **Вход:** через 0,25 с после сигнала по встречной лучшей цене (покупка по ask, продажа по bid), как в лаборатории. «По движению» — в сторону события, «против» — в обратную.
- **Стоп:** `стоп × обычная минутная свеча монеты` от цены входа. Обычная свеча — средний размах (максимум − минимум) / минимум минутных свечей за час до события; нужно не меньше 30 минут истории. Стоп срабатывает, когда цена выхода (bid для лонга, ask для шорта) в какой-то секунде дошла до него. Исполнение — по худшей цене этой секунды, то есть консервативно.
- **Выход по времени:** через заданное удержание (до 5 минут) по встречной цене. Если в эту секунду стакан монеты не обновлялся, выход переносится на следующую секунду со свежим стаканом: подставлять цену, которой не было, нельзя.
- Позиция, которую запись оборвала раньше выхода, **не закрывается выдуманной ценой**. Она исключается из итогов и считается в «не закрыты к концу записи».

## Размер позиции от риска

Риск на сделку (по умолчанию **1,5% депозита**) — это потеря при стопе **вместе с комиссиями**:

```
номинал = депозит × риск% ÷ (расстояние до стопа% + комиссии круга%)
комиссия в долях риска = комиссии круга ÷ (стоп + комиссии круга)
```

Пример: депозит 100 USDT, обычная свеча 0,3%, стоп 2 свечи = 0,6%, комиссии 0,1%. Номинал = 1,5 ÷ 0,7% ≈ 214 USDT, плечо ≈ 2,1x. При стопе убыток 1,29 USDT по цене и 0,21 USDT комиссий, всего 1,5 USDT. Депозит — текущий: после прибыли размер растёт, после убытка уменьшается.

## Когда сигнал пропускается

Причины показываются на странице бота со счётчиком:

- вне выбранных торговых сессий (`Sessions`; ни одной не выбрано — бот торгует во все часы);
- комиссия заняла бы больше допустимой доли риска (по умолчанию 30%). Это монеты с маленьким ходом, например BTC и ETH на спокойном рынке: стоп близко, номинал и плечо большие, комиссия съедает риск;
- достигнут предел одновременных сделок (по умолчанию 3) или по монете уже есть сделка;
- не хватает депозита с учётом предельного плеча (по умолчанию 20x на все открытые сделки) или номинал меньше 5 USDT;
- мало истории монеты для стопа; нет свежего стакана в момент входа;
- достигнут лимит убытка (депозит ≤ начальный − лимит): новые сделки не открываются.

## Данные

Для стопов лаборатория с версии `SignalDetector.Version = 3` хранит ход цены после каждого входа: по секундам 5 минут — последний bid/ask, минимальный bid и максимальный ask среди свежих снимков стакана. Хранится в `signal-path-v1.ndjson` рядом с `signal-lab-v1.json`. При переходе на версию 3 все записи обрабатываются заново; результаты таблицы лаборатории от этого не меняются. В событии хранится и обычная минутная свеча монеты (`TypicalPct`).

Не учтены: проскальзывание глубже лучшей цены (у крупных номиналов будет хуже), funding, ликвидация. Стакан пишется раз в 500 мс, поэтому стоп проверяется по снимкам, а не по каждой сделке.

## API

- `GET /api/v1/bots/{id}/signal` — запуски бота с результатом: сделки, пропуски по причинам, сигналов, не закрытых, депозит, сколько записей прочитано, до какого момента есть данные.
- `POST /api/v1/bots/{id}/signal/start` — `{}` (с этого момента) или `{ "fromMs": … }` (с даты в прошлом); 409, если бот уже работает.
- `POST /api/v1/bots/{id}/signal/stop` — остановить; 409, если не работает.

Бот создаётся как обычный (`POST /api/v1/bots`): `strategy: "signal"`, `symbol: "*"`, `exchange: "Binance"`, настройки в `signal`. Запуски хранятся в таблице `signal_runs` рабочей базы (класс `PaperRunStore`; имя осталось от удалённой симуляции «Поводыря»).

## Чего бот не делает

Это не живая торговля в реальном времени: решения принимаются по записи после её обработки, с задержкой до часа. Для статистики это то же самое, что торговать сразу, ведь решения не используют будущих данных. Для реального счёта понадобится живой режим на потоке записи и торговый адаптер. Это отдельный этап, только с разрешения пользователя.
