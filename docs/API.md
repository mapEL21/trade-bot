# Локальный API v1

ASP.NET Core / .NET 10, слушает только loopback (по умолчанию `http://127.0.0.1:5080`). Vite пересылает `/api` на этот адрес, описание OpenAPI — `/openapi/v1.json`. Это однопользовательский сервер без авторизации. Извне он доступен только на сервере через Tailscale под одним именем `Remote:Host` (`docs/SERVER.md`).

## Боты

| Метод  | Путь                             | Результат                                                                                                   |
| ------ | -------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| GET    | `/api/v1/health`                 | Состояние процесса; `executionEnabled: false`.                                                              |
| GET    | `/api/v1/strategies`             | Каталог: одна стратегия `signal` / `0.2.0`.                                                                 |
| GET    | `/api/v1/workspace`              | Боты (до 100) со статусом и сделками их запусков и последние 200 событий.                                   |
| POST   | `/api/v1/bots`                   | Создать бота; `201`, объект и `Location`.                                                                   |
| GET    | `/api/v1/bots/{id}`              | Бот и `ETag` с номером ревизии.                                                                             |
| PUT    | `/api/v1/bots/{id}`              | Сохранить настройки; `409`, пока бот работает.                                                              |
| DELETE | `/api/v1/bots/{id}`              | Удалить; `409`, пока бот работает.                                                                          |
| GET    | `/api/v1/bots/{id}/signal`       | Запуски бота с результатом (`docs/SIGNAL_BOT.md`).                                                          |
| POST   | `/api/v1/bots/{id}/signal/start` | Запустить: `{}` — с этого момента, `{ "fromMs": … }` — с даты по прошлым записям; `409`, если уже работает. |
| POST   | `/api/v1/bots/{id}/signal/stop`  | Остановить.                                                                                                 |

Тело POST/PUT — настройки бота (`config` из формата импорта): `strategy: "signal"`, `symbol: "*"`, `exchange: "Binance"`, настройки в `signal`. Неизвестные поля отклоняются, максимальный размер запроса 32 КБ, деньги — `decimal`. Боты удалённых стратегий («Поводырь», «Импульс»), сохранённые старыми версиями, остаются в базе, но не показываются и не принимаются.

Изменяющие запросы требуют `X-TradeBot-Client: web`. PUT и DELETE требуют `If-Match: "N"` с текущей ревизией: устаревшая ревизия получает `412`, отсутствующая — `428`. Ошибки приходят в формате Problem Details: `400` — валидация, `403` — источник запроса, `404`, `409` — состояние, `429` — лимит запросов, `503` — SQLite.

Где торгует бот, задаётся при создании полем `execution` настроек: `"simulation"` (по умолчанию), `"testnet"` (демо-счёт Binance, только «Плотность») или `"live"` (реальный счёт, закрыт до решения пользователя). У бота на бирже `budget` = 100, а `lossLimit` — процент; при запуске депозитом становится баланс счёта (`Deposit` бота в `/workspace` — депозит последнего запуска). Такой бот запускается только «с этого момента».

## Биржа

| Метод  | Путь                              | Результат                                                                                        |
| ------ | --------------------------------- | ------------------------------------------------------------------------------------------------ |
| GET    | `/api/v1/exchange/keys`           | Есть ли ключи тестовой сети (последние 4 знака ключа) и разрешён ли реальный счёт.               |
| POST   | `/api/v1/exchange/keys`           | `{ mode: "testnet", apiKey, apiSecret }`: проверить у биржи (баланс) и сохранить зашифрованными. |
| GET    | `/api/v1/exchange/balance/{mode}` | Баланс USDT счёта сейчас: `wallet`, `available`, `unrealized`; `404` без ключей.                 |
| DELETE | `/api/v1/exchange/keys/{mode}`    | Удалить ключи.                                                                                   |
| GET    | `/api/v1/bots/{id}/exchange`      | Журнал заявок последнего запуска (новые сверху, до 100).                                         |

Подробно — `docs/EXCHANGE.md`.

## Запись данных и лаборатория

- `GET/POST /api/v1/scanner`, `POST /api/v1/scanner/{id}/continuous`, `POST /api/v1/scanner/{id}/stop` — запись данных (`docs/LEVEL_BREAKOUT.md`, раздел «Интерфейс и API»).
- `/api/v1/lab/*` — лаборатория сигналов (`docs/SIGNAL_LAB.md`).
- `GET /api/v1/storage` — место на диске и обслуживание записей.

## Хранение

База — `server/TradeBot.Api/data/workspace.db` (в Git не попадает). Таблицы: `bots` и `events` (обновляются одной транзакцией) `signal_runs` (запуски ботов) и `exchange_log` (заявки на бирже). Ключи биржи в базе не хранятся. Повреждённая или более новая база не заменяется пустой.

Настройки окружения:

- `Storage__Path`, `Api__Port`, `Ui__Origin`;
- `Scanner__Path` — каталог записей;
- `Lab__AutoProcess` и `Storage__Housekeeping` — их включают launcher и сервер.
