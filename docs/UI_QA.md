# Проверка интерфейса

Дата: 8 октября 2026 года. Среда: локальный Vite, Edge через Playwright.

## Проверено

- Создание бота, изменение статуса, сохранение после перезагрузки, экспорт, импорт и удаление.
- Вкладки карточки, периоды сделок и сохранение журнала после переименования.
- Ошибки импорта и запрет изменения инструмента у бота с историей.
- Восстановление повреждённого localStorage только после явного сброса.
- Главный экран на ширинах 375, 768 и 1440 px: нет горизонтального переполнения, ошибок JavaScript и HTTP-ответов 4xx/5xx.
- На тех же ширинах: axe не обнаружил нарушений проверяемых правил WCAG A/AA на главном экране и в форме создания.
- Форма открывается с клавиатуры, фокус переходит в название бота, Escape закрывает окно и возвращает фокус к кнопке открытия.
- Скриншоты desktop и mobile просмотрены; график и карточки помещаются на экран.

Исправлены недостаточный контраст подписей, разметка подсказки и первоначальный фокус диалога.

## Ограничения проверки

Визуальная регрессия: **INCONCLUSIVE** — утверждённого эталона ещё нет, полученные скриншоты являются первыми. Проверка скринридером и полевые Core Web Vitals не выполнялись. Автоматический axe-аудит не является полной сертификацией доступности всех экранов.

Функциональные проверки позволяют использовать интерфейс как локальный демопрототип. Готовность к реальной торговле не оценивается: движок и подключения отсутствуют.
