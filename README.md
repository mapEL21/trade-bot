# Trade Bot

Платформа для автоматизированной торговли фьючерсами с веб-интерфейсом, управлением собственными ботами и отдельной статистикой по каждому боту.

**Статус:** проектирование. Код приложения, торговый движок и подключения к биржам пока не реализованы.

## Первая версия

- Один бот и одна стратегия; первый кандидат для исследования — импульсная торговля.
- Один бессрочный фьючерс на альткоин. BTC и ETH исключены из первого отбора.
- Выбор биржи среди Binance, Bybit и OKX по фактическим комиссиям аккаунта, доступности API, ограничениям заявок и качеству исполнения.
- Подключение собственного бота к TigerX пока не подтверждено. Поддержка стандартного биржевого API не означает совместимость с TigerX.
- Баланс около 10 USDT — целевой размер теста механики исполнения, если позволяют минимальный ордер и требования к марже. Доходность такого теста не служит оценкой устойчивости стратегии.
- Список ботов, карточка со статистикой, настройки, история сделок и журнал событий.
- Импорт и экспорт настроек наших стратегий с указанием версии; без API-ключей и стороннего исполняемого кода.
- Явное разделение демонстрационных данных, симуляции и реальной торговли.

## Как пользоваться будущим приложением

1. Открыть страницу «Мои боты».
2. Создать бота из доступной стратегии или импортировать его настройки.
3. Выбрать подключение, инструмент, параметры и ограничения риска.
4. Запустить симуляцию.
5. Открыть карточку бота: график результата, сделки, текущая позиция, комиссии и журнал.

Стратегия описывает алгоритм. Бот — отдельный экземпляр стратегии с конкретным аккаунтом, инструментом, версией и настройками.

## Технологии

| Компонент | Выбор |
| --- | --- |
| Торговый движок и стратегии | C# / .NET |
| Сервер приложения и API | ASP.NET Core |
| Веб-интерфейс | React / TypeScript |
| Настройки, заявки, исполнения и статистика | PostgreSQL |
| Исследование записей рынка | Python при необходимости |

Версии среды, библиотеки и способ развёртывания выберем при создании каркаса приложения.

## Принципы работы

- Закрытие браузера не останавливает торговый движок.
- «Пауза» запрещает новые входы, продолжая управление открытой позицией.
- «Остановить и закрыть» — отдельное действие; отправленная заявка на закрытие ещё не означает закрытую позицию.
- Каждая заявка и исполнение связаны с ботом и версией стратегии.
- Ограничения аккаунта действуют дополнительно к ограничениям бота.
- Реализованный PnL, нереализованный PnL, комиссии, funding и кешбэк учитываются отдельно.
- Реальная торговля выключена по умолчанию.
- Ключи, секреты, выгрузки аккаунтов и приватные торговые данные не публикуются в репозитории.
