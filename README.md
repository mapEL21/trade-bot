# Trade Bot

Локальное приложение для поиска торговых сигналов на криптофьючерсах и бота, который их торгует. Интерфейс — React / TypeScript, сервер — ASP.NET Core / .NET 10, база — SQLite.

## Разделы

- **Обзор** — общий результат ботов: PnL с комиссиями и без, баланс, просадка, качество и история сделок.
- **Боты** — бот «Сигнал лаборатории» ([docs/SIGNAL_BOT.md](docs/SIGNAL_BOT.md)). Торгует выбранный сигнал на всех монетах записи данных, размер позиции считается от риска на сделку с учётом комиссий.
- **Лаборатория**:
  - **Лаборатория сигналов** ([docs/SIGNAL_LAB.md](docs/SIGNAL_LAB.md)) — что дала бы сделка после каждого события рынка с учётом спреда и комиссий, по сессиям; проверка зафиксированной гипотезы;
  - **Плотности** ([docs/DENSITY_SCREENER.md](docs/DENSITY_SCREENER.md)) — скринер крупных заявок в стаканах всех фьючерсов Binance и что с ними стало (проели, сняли);
  - **Запись данных** — сделки, стакан и ликвидации самых торгуемых фьючерсов, непрерывно.

## Первая версия

Цель первой версии — бот «Сигнал лаборатории» на реальном счёте около 10 USDT. Этот счёт проверяет механику исполнения, а не доходность. План:

1. Живой режим: бот торгует виртуально прямо на потоке записи, сделки видны сразу.
2. Торговый адаптер биржи (Binance USDT-M через TigerX; совместимость API и фактические комиссии ещё проверяются). Сначала тестовая сеть. Стоп выставляется на бирже. Состояние сверяется с биржей. Жёсткие лимиты риска.
3. Реальные заявки — только после явного решения пользователя. Ключи вводит сам пользователь, в Git и базу они не попадают.

Сейчас всё работает в симуляции: реальных заявок и ключей нет. Гипотеза о сигнале ещё проверяется на новых данных: 50 эпизодов на сигнал.

## Запуск

**Windows:** двойной клик **«Запустить Trade Bot.cmd»**. Он соберёт и запустит сервер и сайт, а затем откроет браузер. **«Остановить Trade Bot.cmd»** штатно завершает запись данных и останавливает только процессы этого запуска. `node`, `pnpm` и `dotnet` в `PATH` не нужны: скрипт находит локальные инструменты. Журналы запуска лежат в `artifacts/launcher/`.

**Сервер 24/7:** «Обновить сервер.cmd» ставит приложение на Linux-сервер как службу, доступ через Tailscale. Подробно — [docs/SERVER.md](docs/SERVER.md).

**Вручную** (Node.js 22.18+, pnpm 11, .NET SDK 10):

```sh
pnpm install --frozen-lockfile
pnpm build:api
pnpm dev:api
```

Во втором терминале `pnpm dev`, затем откройте http://127.0.0.1:5173. API слушает только локальный адрес, порт 5080. База лежит в `server/TradeBot.Api/data/workspace.db`, записи — в `server/TradeBot.Api/data/scans/`. Ни то, ни другое не публикуется.

## Проверки

```sh
pnpm build
pnpm test
pnpm test:api
pnpm test:ui
```

Браузерные тесты в Windows запускаются через Edge: `$env:PLAYWRIGHT_CHANNEL = 'msedge'`. Перед ними нужен `pnpm build:api`. Тесты поднимают отдельные серверы на портах 5081 и 5175 со своей базой в `artifacts/`.

## Импорт и экспорт бота

JSON содержит только настройки бота. Неизвестные поля, API-ключи и неизвестные версии отклоняются, максимальный размер — 32 КБ.

```json
{
  "schemaVersion": 1,
  "config": {
    "name": "Вынос цены · 5 мин",
    "exchange": "Binance",
    "symbol": "*",
    "budget": 100,
    "lossLimit": 30,
    "strategy": "signal",
    "strategyVersion": "0.1.0",
    "signal": { "signal": "Вынос цены", "mode": "follow", "holdSeconds": 300, "riskPct": 1.5 }
  }
}
```
