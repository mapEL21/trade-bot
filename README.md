# Trade Bot

Платформа для автоматизированной торговли фьючерсами с веб-интерфейсом, управлением собственными ботами и отдельной статистикой по каждому боту.

**Статус:** готов интерактивный прототип веб-интерфейса на React / TypeScript. Торговый движок, сервер и подключения к биржам ещё не реализованы.

В интерфейсе можно создавать, дублировать и удалять демоботов, импортировать и экспортировать их настройки, смотреть график результата, сделки и журнал каждого бота. Изменения сохраняются в localStorage текущего браузера. Есть мобильная версия, поиск и фильтры.

Все сделки, цены и комиссии демопримера вымышлены. ARBUSDT выбран только для оформления примера. Кнопки запуска, паузы и остановки меняют локальный статус: симуляция рынка и отправка заявок пока отсутствуют. Периоды графика отсчитываются от фиксированной даты демоданных — 7 октября 2026 года. PnL рассчитан после вымышленных комиссий; funding и кешбэк ещё не моделируются.

## Первая версия

- Один бот и одна стратегия; первый кандидат для исследования — импульсная торговля.
- Один бессрочный фьючерс на альткоин. BTC и ETH исключены из первого отбора.
- Выбор биржи среди Binance, Bybit и OKX по фактическим комиссиям аккаунта, доступности API, ограничениям заявок и качеству исполнения.
- Подключение собственного бота к TigerX пока не подтверждено. Поддержка стандартного биржевого API не означает совместимость с TigerX.
- Баланс около 10 USDT — целевой размер теста механики исполнения, если позволяют минимальный ордер и требования к марже. Доходность такого теста не служит оценкой устойчивости стратегии.
- Список ботов, карточка со статистикой, настройки, история сделок и журнал событий.
- Импорт и экспорт настроек наших стратегий с указанием версии; без API-ключей и стороннего исполняемого кода.
- Явное разделение демонстрационных данных, симуляции и реальной торговли.

## Как пользоваться прототипом

1. Открыть страницу «Мои боты».
2. Создать бота из доступной стратегии или импортировать его настройки.
3. Задать биржу, символ фьючерса, демобаланс и лимит убытка.
4. Открыть карточку бота и проверить вкладки «Обзор», «Сделки», «Настройки» и «Журнал».
5. Экспортировать конфигурацию в JSON или сделки примера в CSV.

Новые боты создаются без сделок. Менять биржу, символ и начальный баланс бота с историей можно через создание копии, чтобы не приписывать старые результаты новым настройкам. Сброс локальных данных находится в разделе «Подключения» и требует подтверждения в интерфейсе.

Стратегия описывает алгоритм. Бот — отдельный экземпляр стратегии с конкретным аккаунтом, инструментом, версией и настройками.

## Технологии

| Компонент                                  | Выбор                    |
| ------------------------------------------ | ------------------------ |
| Торговый движок и стратегии                | C# / .NET                |
| Сервер приложения и API                    | ASP.NET Core             |
| Веб-интерфейс                              | React / TypeScript       |
| Настройки, заявки, исполнения и статистика | PostgreSQL               |
| Исследование записей рынка                 | Python при необходимости |

Сейчас реализован только клиент на React 19 и Vite 7. Остальные компоненты таблицы запланированы.

## Требования к будущему торговому движку

- Закрытие браузера не останавливает торговый движок.
- «Пауза» запрещает новые входы, продолжая управление открытой позицией.
- «Остановить и закрыть» — отдельное действие; отправленная заявка на закрытие ещё не означает закрытую позицию.
- Каждая заявка и исполнение связаны с ботом и версией стратегии.
- Ограничения аккаунта действуют дополнительно к ограничениям бота.
- Реализованный PnL, нереализованный PnL, комиссии, funding и кешбэк учитываются отдельно.
- Реальная торговля выключена по умолчанию.
- Ключи, секреты, выгрузки аккаунтов и приватные торговые данные не публикуются в репозитории.

## Запуск и проверка

Нужны Node.js 22.18+ и pnpm 11.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Открыть http://127.0.0.1:5173. Шрифт включён в сборку; внешних сервисов для работы интерфейса не требуется. Данные хранятся только в этом браузере и не синхронизируются между устройствами.

```sh
pnpm build
pnpm test
pnpm exec playwright install chromium
pnpm test:ui
```

В Windows можно использовать установленный Edge без загрузки Chromium:

```powershell
$env:PLAYWRIGHT_CHANNEL = 'msedge'
pnpm test:ui
```

Тесты проверяют расчёт статистики, валидацию импорта, работу с локальным хранилищем и пользовательские сценарии. Скриншоты сохраняются в игнорируемую папку `artifacts/`.

## Формат импорта

JSON содержит только конфигурацию поддерживаемого шаблона. Неизвестные поля, API-ключи и неизвестные версии отклоняются. Максимальный размер файла — 32 КБ.

```json
{
  "schemaVersion": 1,
  "config": {
    "name": "Мой импульс",
    "exchange": "Binance",
    "symbol": "ARBUSDT",
    "budget": 10,
    "lossLimit": 1,
    "strategy": "impulse",
    "strategyVersion": "0.1.0"
  }
}
```

Доступность символа на бирже и достаточность маржи в прототипе не проверяются. Импорт не переносит программный код, историю сделок или статус запуска.
